# 설계 메모: 커스텀 묶음과 숙제 단어

- 작성일: 2026-10-11
- 범위: 묶음 이름 변경, 사진 등록에서 Day별 묶음 만들기
- 이 메모가 바꾸는 규칙은 PRD·TRD·`2026-10-08-my-words.md`보다 우선한다

## 문제

학원 종이에는 숙제 단어도 내 단어도 아닌 단어(예: 독해 파트)가 있다. 지금은 묶음이 `class`·`mine` 둘로 고정돼 있어 이런 단어를 따로 모을 수 없다.

## 결정

### 이름과 순서

- 화면의 '수업 단어'를 모두 '숙제 단어'로 바꾼다. 저장 값 `class`는 그대로다.
- 학습 시트의 '둘 다' 칩은 '전체'로 바꾼다. 묶음이 셋 이상일 수 있다.
- Day 화면 순서: 숙제 단어 → 내 단어(+ 단어 추가) → 커스텀 묶음들 → 숨긴 단어.
  - 커스텀 묶음끼리는 만든 순서(그 묶음 단어의 가장 작은 위치)다.
  - 커스텀 묶음은 숨기지 않은 단어가 있을 때만 보인다. 숙제·내 단어 머리줄은 지금처럼 늘 보인다.
- 목록에서 여는 카드 보기도 같은 순서다.

### 커스텀 묶음

- 그 Day에만 속한다. 다른 Day의 같은 이름 묶음과 상관없다.
- 사진 등록(올리기 화면, 초안 미리보기)에서만 만든다. Claude Code 등록 API와 '단어 추가'는 지금처럼 `class`·`mine`만 쓴다.
- 관리 화면이 없다. 단어가 하나도 남지 않으면 묶음도 없어진다.
- 이름: 앞뒤 공백을 지우고 연속 공백을 하나로 줄인 1~12자. '숙제 단어'·'내 단어'·'숨긴 단어'는 쓸 수 없다. 같은 이름이면 같은 묶음이다.
- 이미 있는 단어를 커스텀 묶음으로 등록하면 숙제 단어와 같은 규칙이다.
  - 같은 Day의 내 단어면 그 묶음 끝으로 옮기고 `moved`로 알린다.
  - 숙제 단어나 다른 커스텀 묶음에 있으면 건너뛴다(`skipped`).

### 사진 등록 화면

- 묶음 칩: 숙제 단어 / 내 단어 / 다른 묶음.
- '다른 묶음'을 고르면 이름 칸이 나온다. 입력한 Day에 이미 있는 커스텀 묶음 이름이 빠른 선택 칩으로 함께 나온다.
- Day 번호는 내 단어처럼 직접 넣는다. 숙제 단어로 돌아가면 다음 번호를 다시 제안한다.
- 초안 줄과 처리 중 화면은 `Day 03 · 독해`처럼 묶음 이름을 적는다.

### 학습

- Day 학습 시트 칩: 전체 / 숙제 단어 / 내 단어 / 그 Day의 커스텀 묶음들.
- 커스텀 묶음 선택은 기억하지 않는다. 다음에는 기억한 기본 묶음으로 연다.
- 통합·북마크 학습: 커스텀 묶음 단어는 '전체'에만 들어간다.

### 데이터

- 마이그레이션 v4에서 `day_words`와 `drafts`를 다시 만든다. SQLite는 CHECK를 바꿀 수 없다.
  - `section`에 `'custom'`을 더하고 `custom_name TEXT`를 둔다.
  - `CHECK ((section = 'custom') = (custom_name IS NOT NULL))`
  - 기존 행은 값 그대로 옮기고 `day_words_word_id` 인덱스를 다시 만든다.
- 묶음 테이블은 따로 두지 않는다. 이름이 행에 있으니 비면 저절로 없어진다.
- `DayWord`·`Draft`에 `customName: string | null`을 더한다. Day 조회 API도 같이 돌려준다.
- 묶음 수정 API(`PATCH /api/days/[n]/words/[id]`)는 `class`·`mine`만 받는다. 커스텀 단어를 옮기면 `custom_name`을 지운다.

## 기각한 대안

- 묶음 테이블(`day_sections`): 이름 바꾸기·빈 묶음 유지가 없으니 필요 없다.
- 커스텀 단어를 `section = 'class'` + 이름으로 저장해 테이블 재생성을 피하기: 숙제 단어를 고르는 모든 쿼리에 조건을 덧붙여야 해서 틀리기 쉽다.
- 전체 공용 묶음, Day 화면의 이름 바꾸기·삭제: 사용자가 Day 단위·관리 없음을 골랐다.

## 비목표

- 커스텀 묶음 이름 바꾸기·삭제·순서 바꾸기
- 단어를 다른 묶음으로 옮기는 화면
- Claude Code 등록 API로 커스텀 묶음 만들기

## 가정

- 커스텀 묶음은 Day마다 몇 개 안 된다. 많아지면 학습 시트 칩이 줄을 넘긴다(칩은 이미 줄바꿈된다).
- 배포 DB 사본에서 v3 → v4가 행 수와 묶음 값을 그대로 옮긴다. 틀리면 단어가 사라지므로 머지 전에 확인한다.
