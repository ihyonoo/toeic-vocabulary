### 코드 리뷰 처리 (블로킹 1, 고친 부분 재리뷰 1회)

| 지적 | 처리 |
|---|---|
| 세션 쿠키가 비밀번호만으로 계산돼(공개 저장소) 쿠키로 비밀번호를 무제한 대입 가능 (블로킹) | 수용. `SESSION_SECRET`으로 서명, 32자 미만이면 시작 안 함. 재리뷰에서 재현이 막힘을 확인 |
| 로그인 API가 본문을 기다리는 동안 차단 검사가 낡아 10번을 넘김 | 수용. 본문을 읽은 뒤 비밀번호 확인 직전에 검사 |
| Compose가 빠진 변수를 빈 문자열로 넘겨 조용히 잘못 동작 | 수용. `${VAR:?}` 필수 표시 |
| 서버 `.env` 값의 `$`를 Compose가 잘라도 못 잡음 (재리뷰) | 수용. 서버 `.env` 값을 작은따옴표로 감쌈 |
| 빈 IP 주소면 Bearer 집계를 건너뜀 (재리뷰) | 수용 |
| 로그인 API에 Bearer를 같이 보내면 두 번 셈 | 수용. 훅은 로그인 API를 세지 않음 |
| 실패마다 전체 기록을 돌아 IP가 많으면 비용이 제곱으로 늘어남 | 수용. 1분에 한 번 정리 |
| main 빌드 순서가 뒤집히면 `latest`가 옛 커밋 | 수용. 워크플로 수준 `concurrency` |
| 다른 프로젝트의 이미지 정리와 겹치면 성공한 배포가 실패로 보고 | 수용. 정리 실패는 무시 |
| Dockerfile 주석에 서버 사용자 이름 (설계: 공개 저장소에 적지 않음) | 수용 |
| 진행 기록·사진 등록 PRD 머리말·마이그레이션 확인 절차 누락 | 수용 |
| E2E 제한 테스트를 같은 서버에서 두 번 돌리면 깨짐 | 보류. 기본 설정은 매번 서버를 새로 띄움 |
